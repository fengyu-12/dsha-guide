DSHA 新手避坑指南

从装上到能用：6 步拿到并填入 API Key

一句话说明：DSHA 启动后会自己弹出密钥框，流程就是「去 DeepSeek 开放平台建 key → 复制 → 回来粘贴 → 进 Web 界面」。 能进去就行，后面的事交给 agent 做。

一、创建并填入 API Key

1

启动后先看到这个弹窗

启动 DSHA → 自动打开 Web 界面 → 弹出「添加一个 API Key 开始使用」。

  • 还没有 key：点「稍后配置」，接着看第 2 步。
  • 已经有 key：直接跳到第 6 步。
2

在 DeepSeek 开放平台登录

打开 platform.deepseek.com，填「+86 手机号」→ 点「发送验证码」→ 填验证码 → 点「登录」。

  • 没注册过的手机号会自动注册，不用单独走注册流程。
  • 也可以用底部的「密码登录」。
3

创建 API key

进 platform.deepseek.com/api_keys → 点右上角「创建 API key」。

  • 单个账号最多保留 200 个 API key。
  • 已被公开泄露的 key，平台会自动禁用。
4

起名字，点创建

弹窗里输入名字 → 点「创建」。名字只为区分用途，随便写。

  • 示例：dsha-手机、dsha-平板、dsha-小米14、测试。
5

立刻复制（最关键）

创建成功后弹窗会直接显示完整 key，点右侧「复制」按钮。

  • 页面原话：出于安全原因，你将无法通过 API keys 管理界面再次查看它；丢失需要重新创建。
  • 所以当场就复制，先粘到记事本，或者直接粘进 DSHA。
6

回到弹窗粘贴

把 key 粘进「API 密钥」框 → 点「保存并继续」，就能进 Web 界面了。

  • 当时点了「稍后配置」也不会丢：之后到「配置 → 模型配置」里补就行。
  • 在模型配置里：选好服务商后，地址、协议、模型目录都是预设好的，只填 API Key，别改。

二、常见问题速查

选包已验证

手机装不上 / 闪退

原因：只支持 arm64 + Android 6 以上

怎么办：确认机型是 arm64；Android 11+ 装标准版，6~10 装 Low 版

来源：官方 README

选包已验证

打开就白屏

原因：系统 WebView 版本旧

怎么办：改装 Low 版（内置 GeckoView 143，不依赖系统 WebView）

来源：官方 README

密钥已验证（用户确认）

「我知道 api 地址和 apikey 为啥还是不行」

原因：地址/模型目录是预设的，通常只需填 API Key；填了还不行多半是 key 本身或选了中转站没改地址

怎么办：服务商选 DeepSeek → 只填 API Key（其余保持预设）；接中转站才手动改地址

来源：群聊 2026-10-19 22:39 + DSHA 配置页截图

密钥已验证

群友分享的免费 key 用几小时就失效

原因：共享 key 有有效期，非永久

怎么办：自己到 DeepSeek 开放平台申请

来源：群聊 2026-10-19 23:50

地址已验证

「Api 地址是哪个啊」

原因：不知道 base_url 该填什么

怎么办：DeepSeek 官方填 https://api.deepseek.com（官方文档口径）；第三方中转站按其说明，多为 https://xxx/v1

来源：DeepSeek 官方文档

地址已验证

key 是对的但连不上

原因：地址写成了完整端点，或漏了路径

怎么办：只填 base_url，不要带 /chat/completions

来源：实测（本机接第三方网关）

报错推断

401 Unauthorized

原因：key 错误 / 过期 / 与地址不是同一家

怎么办：核对 key 与地址是否配套

来源：通用经验

报错推断

404 Not Found

原因：地址路径多写或少写

怎么办：检查是否误带 /chat/completions

来源：通用经验

报错推断

连接超时

原因：域名写错或网络受限

怎么办：核对域名；换网络环境

来源：通用经验

报错推断

402 余额不足

原因：DeepSeek 账户无余额

怎么办：到开放平台充值

来源：通用经验

白屏已验证（issue）

「进入不了 dsh 页面，点完确认会卡在这一步」

原因：Web 进程或网页内核异常

怎么办：换 WebView 实现 → 清缓存 → 装 Low 版 → 导出诊断报告

来源：GitHub issue #157 / #149

WebView推断

「华为 在应用管理找不到 webview 怎么搞」

原因：较新 Android 上 WebView 由 Chrome 提供，列表里显示为 Chrome

怎么办：到设置里找「WebView 实现」并切换到 Chrome 或 WebView Beta

来源：群聊 2026-10-19 22:50 + Android 通用机制

启动失败已验证（原话）

诊断报告：停止旧 Web 进程 / DENIED

原因：旧 Web 进程残留，手动杀不掉

怎么办：重启手机；这是群内实测有效的办法

来源：群内诊断报告 2026-10-19 23:51

启动失败已验证（原话）

诊断报告：proot 进程退出，退出码 1（鉴权前）

原因：环境层起不来，不是 key 问题

怎么办：用「安装与修复」逐项检查，或进「独立应急 DSH」

来源：群内诊断报告 2026-10-19 23:52

数据已验证

卸载重装后数据没了

原因：数据在私有目录时卸载即丢

怎么办：卸载前「数据与备份 → 导出」

来源：官方 README

局域网已验证（issue）

局域网访问不可用，拿不到凭据

原因：LAN token / 网络环境问题

怎么办：同一 WiFi；仍不行看 issue #168

来源：GitHub issue #168

安装已验证（issue）

签名校验失败

原因：装过不同签名的改包

怎么办：卸载后装官方包（会丢数据，先备份）

来源：GitHub issue #152

安装已验证（issue）

首次安装失败

原因：系统版本 / 架构 / 空间不足

怎么办：确认 Android 版本与 arm64；至少留 1 GB 空间

来源：GitHub issue #166
